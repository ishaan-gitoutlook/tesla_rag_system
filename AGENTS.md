# Project instructions

This repository is a Flask RAG application for Tesla's 2023 Form 10-K.

- Use `.venv` when available.
- Run `python -m pytest -q` for tests.
- Compile project source files only; exclude `.venv`.
- Never commit API keys, `.env` files, model caches, or bytecode.
- Validate API input at the boundary and preserve local generation as the default.
